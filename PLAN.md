# ИИ-помощник для каталогизации 3D-моделей и подбора настроек 3D-печати

> Проектная задача программы «Сириус.Лето». Партнёр: БФУ им. И. Канта.

**Краткая суть:** интеллектуальный ассистент, который раскладывает библиотеку
3D-моделей по смысловым папкам и готовит профили печати для популярных слайсеров.

## 1. Актуальность (зачем это нужно)

### Проблема
- Специалистам по 3D-моделированию и 3D-печати сложно классифицировать создаваемые ими 3D-модели.
- Работа подразумевает многократное создание разнообразных версий моделей, между которыми возникает путаница.
- Путаницу усугубляет необходимость подбирать параметры слайсера для 3D-печати.

### Решение
Приложение с ИИ-помощником, который сам раскладывает библиотеку 3D-моделей
по смысловым папкам и предлагает профиль печати для популярных слайсеров.

### Пример работы (иллюстрация со слайда)
Папка «Загрузки» с неструктурированными файлами → ИИ → «Библиотека» с папками классов:

| Папка класса | Файлы |
|---|---|
| Вазы | `final_v3.stl`, `final_v3_fix.stl` |
| Фигурки | `model (2).obj`, `new_new.stl` |
| Крепёж | `print_ok.3mf` |
| Корпуса | `untitled.stl`, `test1.ply` |

## 2. Цель проекта

Разработать интеллектуального ассистента и обучить связанную с ним модель
машинного обучения, классифицирующую трёхмерные модели по их геометрии.
Ассистент раскладывает 3D-модели из пользовательских папок по папкам с понятными
названиями классов и готовит рекомендованные профили печати с экспортом
в форматы популярных слайсеров.

### Архитектура

#### Приложение — компьютер пользователя
- Программный комплекс на Python:
  - сканирование папок;
  - фоновое отслеживание новых файлов (`watchdog`);
  - вычисление модели через ONNX Runtime.
- Безопасное перемещение файлов: просмотр плана, журнал, отмена.

#### Сервер лаборатории — обучение
- Обучение моделей на PyTorch на вычислительном сервере лаборатории астрофизики БФУ им. И. Канта.
- Наборы данных и промежуточные представления — около 100–150 ГБ.
- Обученная модель экспортируется в ONNX и передаётся в приложение.

## 3. Задачи проекта (шесть блоков работы)

1. **Предметная область** — полигональные сетки и распространённые форматы 3D-моделей, технология FDM-печати и назначение настроек слайсера.
2. **Машинное обучение** — классификация 3D-моделей по геометрии: предобработка, обучение на PyTorch, сравнение подходов, журнал экспериментов.
3. **Приложение-помощник** — раскладывание моделей по папкам классов и профили печати с экспортом в PrusaSlicer, OrcaSlicer и Cura.
4. **Фоновый режим** — отслеживание новых файлов, безопасное перемещение с предварительным просмотром плана, журналом и отменой.
5. **Валидация** — отложенная часть ShapeNetCore v2 и независимый набор печатных моделей; сравнение с PointNet, PointNet++ и DGCNN на ModelNet40.
6. **Документация и защита** — техническая и отчётная документация, представление проекта проектантам и экспертному сообществу.

## 4. Планируемый результат

### Приложение-помощник
- Прототип для 3D-художников и специалистов по 3D-печати, разработанный и апробированный.
- Библиотека моделей по смысловым папкам; профиль печати для своего слайсера с пояснением каждого значения.

### Модель и данные
- Обученная модель классификации 3D-моделей.
- Размеченный набор реальных печатных моделей и таблица соответствия настроек популярных слайсеров.

### Документация
- Необходимая техническая документация.
- Иллюстративные и презентационные материалы по результатам проекта.

**Междисциплинарный результат:** вычислительная геометрия, машинное обучение
на трёхмерных данных и аддитивные технологии сходятся в одном работающем приложении.

## 5. Участники и наставник

### На кого рассчитан
- Школьники 8–11 классов с навыками программирования на Python и знанием геометрии в объёме школьного курса, интересующиеся машинным обучением и 3D-моделированием.
- Команда из 4–6 человек.
- Приветствуются: scikit-learn или PyTorch, опыт работы с Git, собственный опыт 3D-моделирования или 3D-печати.

### Деятельность участников
- **Обучение:** предобработка геометрии, обучение и сравнение моделей на PyTorch, журнал экспериментов.
- **Разработка:** архитектура и код приложения, геометрические признаки, правила подбора настроек, конвертеры профилей.
- **Проверка:** на незнакомой библиотеке моделей, документация, представление результатов.

### Деятельность наставника
- Вводит в предметную область, контролирует уровень компетенций, проводит код-ревью, отдельно следит за безопасностью файловых операций.
- Помогает выбрать стек, учит работе с Git, разъясняет правила использования сторонних 3D-моделей.
- Планирует этапы и контрольные точки, распределяет роли, готовит к защите.

### Компетенции
Трёхмерные данные и геометрия сеток, обучение и объективная оценка моделей
машинного обучения, Python, разработка ПО, аддитивные технологии,
воспроизводимые исследования и научная коммуникация.

## 6. Условия реализации (площадка, оборудование, материалы)

### Площадка и оборудование
- Обучение — на вычислительном сервере лаборатории астрофизики БФУ им. И. Канта; данные — на сервере хранения лаборатории.
- У каждого участника и наставника — компьютер не менее чем с 8 ГБ оперативной памяти и многоядерным процессором.
- Желателен FDM-3D-принтер для проверки профилей реальной печатью.

### Программное обеспечение (всё бесплатно и открыто)
- Python 3 с библиотеками: `trimesh`, `Open3D`, `PyTorch`, `scikit-learn`
- Слайсеры: PrusaSlicer, OrcaSlicer, Cura
- Инструменты: Git, Jupyter

### Техника безопасности при работе с принтером
- Сопло и стол нагреваются до 200–260 °C.
- ABS — только в проветриваемом помещении.
