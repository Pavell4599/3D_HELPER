# 3D Helper

3D Helper распознаёт 3D-модели с помощью PointNet и предлагает примерные
настройки FDM-печати для 40 классов ModelNet40. Названия классов нужны модели
на английском; в ответах API также есть русские названия и советы.

## Установка

Все команды запускайте из корня репозитория. Установите зависимости один раз:

```bash
python -m pip install -r requirements.txt
```

## Настольное приложение

```bash
python -m Backend.desktop_app
```

Выберите папку с моделями и нажмите **«Сканировать»**. Чтобы разложить файлы
по классам, нажмите **«Разложить по папкам классов»** и подтвердите действие.
Кнопка **«Вернуть файлы»** отменит перемещение. История операций хранится в
`%USERPROFILE%\\.3d_helper\\operations`, поэтому отмена доступна и после
перезапуска.

## Сайт и API

Откройте два терминала в корне репозитория. В первом запустите API:

```bash
python -m uvicorn Backend.main:app --host 127.0.0.1 --port 8001
```

Порт `8001` используется вместо часто занятого `8000`. Во втором терминале
запустите сайт:

```bash
python -m http.server 8080 --directory Frontend/src_matv
```

Откройте <http://127.0.0.1:8080>, выберите модель и нажмите
**«Анализировать модель»**. Для сортировки набора моделей выберите папку и
скачайте ZIP. Файлы в архиве сгруппированы по классам; оригиналы на компьютере
не меняются.

Оставьте оба терминала открытыми, пока пользуетесь сайтом. Для остановки
нажмите `Ctrl+C` в каждом. Если порт `8001` тоже занят, остановите старый
сервер в его терминале и запустите команду снова.

Документация API: <http://127.0.0.1:8001/docs>. Основные маршруты:
`/health`, `/classes`, `/settings`, `/analyze-model`, `/organize-upload`,
`/scan` и `/organize`. Для запросов к локальным папкам API использует
локальные пути; `/organize` сначала только показывает план, а для возврата
перемещённых файлов предусмотрен `/undo/{operation_id}`.

## Примечания

Веса модели находятся в `Backend/Ai/best_pointnet_modelnet40.pth`. Путь можно
изменить через переменную окружения `POINTNET_WEIGHTS`.

Параметры PLA в `Data/settings/modelnet40.json` — отправная точка, а не
универсальный профиль. Перед печатью проверьте рекомендации производителя
пластика, ограничения принтера и предпросмотр в слайсере. API по умолчанию
доступен только на этом компьютере; не открывайте его в интернет.
