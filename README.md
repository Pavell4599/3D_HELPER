# 3D Helper

Локальный backend классифицирует 3D-модели с помощью PointNet, обученной на
ModelNet40, и выдаёт ориентировочные советы по FDM-печати для каждого из 40
классов. Названия классов модели остаются на английском для совместимости с
ModelNet40; API также возвращает русские названия и рекомендации.

## Установка и запуск

Выполните команды из корня репозитория:

```bash
python -m pip install -r requirements.txt
python -m Backend.desktop_app
```

Откроется окно приложения. Нажмите **«Выбрать папку…»**, выберите папку,
нажмите **«Сканировать»** для просмотра распознанных классов, затем
**«Разложить по папкам классов»** и подтвердите перемещение. Кнопка
**«Вернуть файлы»** отменит выбранную операцию и вернёт файлы в исходные папки.
Журнал отмены хранится в `%USERPROFILE%\\.3d_helper\\operations`, поэтому его
можно использовать после перезапуска приложения.

Веса модели находятся в `Backend/Ai/best_pointnet_modelnet40.pth`. Путь можно
переопределить переменной окружения `POINTNET_WEIGHTS`.

Для разработки и ручной проверки HTTP API запустите backend отдельно:

```bash
python -m uvicorn Backend.main:app --host 127.0.0.1 --port 8000
```

Интерактивная документация API: <http://127.0.0.1:8000/docs>.

Backend по умолчанию доступен только на этом компьютере и сканирует локальные
папки. Чтобы разрешить запросы с сайта, укажите его адрес в `CORS_ORIGINS`
(несколько адресов разделяются запятыми). Не открывайте локальный backend для
доступа из интернета.

## Основные маршруты API

- `GET /health`, `GET /classes`, `GET /settings`, `GET /settings/{class_name}` —
  состояние, классы и советы по печати.
- `POST /analyze-model` — загрузить одну 3D-модель для классификации.
- `POST /classify-file` — классифицировать файл по локальному пути.
- `POST /scan` — классифицировать модели в локальной папке.
- `POST /organize` — показать план раскладки; файлы не изменяются.
- `POST /organize/apply` — явно скопировать файлы по папкам классов; оригиналы сохраняются.
- `POST /organize-in-place` — переместить файлы в подпапки классов и получить ID операции.
- `GET /operations` и `POST /undo/{operation_id}` — найти и отменить перемещение.

Пример тела запроса для сканирования:

```json
{
  "path": "C:\\Users\\you\\Downloads\\models",
  "recursive": true
}
```

Для `/organize` и `/organize/apply` дополнительно укажите `output_directory`.
Папки источника и назначения не должны пересекаться. Поддерживаемые форматы
перечислены в ответе `GET /classes`.

В `Data/settings/modelnet40.json` заданы конкретные стартовые параметры для PLA
и сопла 0,4 мм: температура, скорость, слой, заполнение, поддержки и кайма, а
также короткий совет для каждого класса. Это ориентир, а не готовый профиль для
любого принтера: перед печатью сверьте параметры с производителем пластика,
ограничениями принтера и предпросмотром в слайсере.
